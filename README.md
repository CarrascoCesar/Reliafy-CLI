# Reliafy Is Now Brinkpy

Reliafy CLI has been renamed **Brinkpy**. Reliafy is no longer maintained, and this final release (0.3.0) only prints a notice pointing to Brinkpy.

Brinkpy is the same software under its new name, with new features and fixes: reliability analysis with the first-order and second-order reliability methods (FORM and SORM), reliability-based design optimization, and Monte Carlo simulation with importance sampling.

## Switch to Brinkpy

```bash
pip uninstall reliafy
pip install brinkpy
brinkpy --help
```

- Documentation: <https://brinkpy.app>
- Brinkpy on PyPI: <https://pypi.org/project/brinkpy/>
- Source code: <https://github.com/BrinkPy/brinkpy-cli>

## Earlier Versions

Reliafy versions 0.1.0 to 0.2.2 remain on PyPI, but they are no longer supported. The code of those versions stays in the history of this repository.
